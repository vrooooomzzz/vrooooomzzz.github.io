# Current Duc Tuan Portfolio Architecture

The public entrypoint mounts a native React single-page portfolio without the Chakra provider. App renders the existing Business-named modules as the public narrative: hero, compact About, three project investigations, process/evidence, combined education/internship journey, and music/community ending. BusinessShell supplies a sticky horizontal header, four anchor links, expandable mobile navigation, motion control, and footer.

The former public template/style and layout switches are superseded by the user-requested reference-informed revision. Legacy registry/layout/storage helpers remain as compatibility code and isolated tests; saved old preferences do not select a different public experience. Old #/section links normalize to section anchors. Prior-owner article URLs produce a safe unavailable-page response.

Public data comes from typed modules under src/data. Only eight reviewed course/professional certificates are imported; private résumé/ZIP and the raw team presentation remain local. Certificate images have a native dialog; the two Coursera previews use locally rendered certificate-page PNGs, with direct links to their unchanged original PDFs.

Responsive CSS uses viewport and container queries, fluid text, stacking project/journey layouts, mobile control wrapping, and reduced-motion rules. Native project controls and keyboard-accessible process tabs explain concepts without claiming live model execution. Production remains a static Vite build suitable for the existing GitHub Pages workflow. No new dependencies or backend are required.

The reference, https://bao252512.github.io/, informed structure, responsive hierarchy, and information organization; Duc Tuan's source-grounded content and private-file boundary remain independent. Detailed verification and historical-source limits are in the code-generation summary and public asset review. Audit history preserves prior architectural decisions.
